# factor-analysis-shopee-satisfaction
Repository ini berisi proyek analisis data multivariat menggunakan **Exploratory Factor Analysis (EFA)** dengan bahasa pemrograman R[cite: 1, 17]. Proyek ini bertujuan untuk mengidentifikasi faktor-faktor utama dan variabel indikator yang memengaruhi kepuasan pengguna platform e-commerce Shopee di kalangan mahasiswa
